# 💰 FinanIA — Organização Financeira com IA

## 📌 Sobre o projeto

O FinanIA é um projeto desenvolvido para o desafio de Vibe Coding da DIO.

A ideia é criar um aplicativo que ajude as pessoas a controlar seus gastos, organizar receitas e despesas e acompanhar metas de economia com apoio de Inteligência Artificial.

## 🎯 Objetivo

Criar um protótipo de aplicativo financeiro de forma simples e prática, utilizando ferramentas de IA para ajudar no planejamento e desenvolvimento.

## 🛠️ Ferramentas utilizadas

- Microsoft Copilot — planejamento e criação do PRD.
- Lovable — desenvolvimento do protótipo.
- GitHub — documentação do projeto.

## 🚀 Funcionalidades planejadas

- Dashboard financeiro.
- Cadastro de receitas e despesas.
- Gráficos de gastos.
- Metas de economia.
- Assistente financeiro conversacional.

## 💡 Aprendizados e conclusões

Com esse projeto, aprendi como a IA pode ajudar a criar um aplicativo a partir de uma ideia, sem precisar programar tudo manualmente.

Também percebi que o Vibe Coding facilita bastante o desenvolvimento, mas é importante usar bons prompts e testar o que foi criado.

## ✅ Resultado final

O projeto teve como resultado a criação de um protótipo do FinanIA, um aplicativo de organização financeira pessoal.

A proposta inclui visualizar receitas e despesas, acompanhar gastos e criar metas de economia, mostrando como a IA pode ajudar no desenvolvimento de soluções para problemas do dia a dia.


Projeto desenvolvido para fins educacionais como parte de um desafio da DIO.
